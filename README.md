# FLOWLY.

Uma experiência moderna de gerenciamento de tarefas inspirada na simplicidade e elegância dos produtos Apple.

## Sobre o projeto

FLOWLY. é uma aplicação web desenvolvida para organizar tarefas de forma simples e intuitiva.

O sistema permite criar, acompanhar e gerenciar atividades utilizando uma interface minimalista com efeito Glassmorphism (meu favoritinho do momento) e armazenamento local no navegador.

## Funcionalidades

- Adicionar tarefas
- Adicionar observações opcionais
- Marcar tarefas como concluídas
- Reabrir tarefas concluídas
- Mover tarefas para a lixeira
- Visualizar tarefas por categoria:
  - Geral
  - A Realizar
  - Realizadas
  - Excluídas
- Dashboard com contadores automáticos
- Armazenamento local (Local Storage)
- Interface responsiva
- Design inspirado na Apple

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- jQuery
- Local Storage

## Objetivo

Este projeto foi desenvolvido para praticar conceitos de desenvolvimento front-end, manipulação do DOM, armazenamento local e criação de interfaces modernas.
